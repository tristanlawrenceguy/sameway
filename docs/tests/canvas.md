# Tests: canvas and tabs

The canvas the model builds: blocks, tabs, layout and its measuring, and blocks checked or set up wrong.

One row per way of using Sameway: what is checked, and where. Add a row here
when you add a way to use the system in this area, with its test.

| Way of using it | Test | Run |
|---|---|---|
| Model lays out and restyles the canvas | span, position, chat as a removable block; arrange_canvas lays a whole tab out as one change and one Undo, refused whole when it loses a block or skips a heading level; every block write ends with a Layout now line (rows and their fill, holes, tall beside short, heading order and repeats, related blocks apart, late below coming, pane sizes) with an arrange_canvas call that fixes it, the same over MCP and REST (`POST /api/arrange`, `layout` in block answers); see design/foundations/layout.md | `internal/chat/layout_test.go`, `internal/chat/arrange_test.go`, `internal/mcp/arrange_test.go`, `internal/server/api/api_arrange_test.go` |
| Layout is measured in the person's browser | 29-measure.js sends each block's size, inner scroll, clipping and overflow past the screen as numbers and ids only, from pages the owner or an editor opens (never published, view-only, agents, save-data or driven browsers); POST /canvas/measure refuses anything else and caps sizes; readings are kept per block and kind of screen and go stale when the block changes or after seven days; Layout now uses measured heights, says measured or estimated, and names an inner scroll, a pane too short, a cut or a sideways overflow with the arrange_canvas call that fixes it; /api/look gives them as measured; the runner checks seeded tabs at desktop and phone widths with the same script | `internal/chat/measured_test.go`, `internal/server/measure_test.go`, `tools/a11y-runner/measure.mjs` (site.mjs) |
| Model uses the canvas tools | add, update, remove, clear, ordering, validation errors, prompt contents, history; the prompt names each component and content type in a line and carries no schema; a call that does not fit is refused with the whole of what it takes (a component's props schema and an example, a type's fields), so nothing is read first | `internal/chat/*_test.go` |
| Model tidies a page in one call | remove_component takes ids for several blocks: one entry ("Assistant removed 3 blocks: Weather note, Old reminder, Leftover card") that one Undo takes back whole, ending with Layout now; all or none, an id that is not a block removes nothing and the error lists the tab's blocks by id and component; one id still removes one; the status says "Removing 3 blocks"; propose_change carries ids too | `internal/chat/remove_test.go` |
| A record is shown on the canvas as itself | a record block renders the record's words with edit markers, edits post to the record and return to the canvas, the expanded block is the record at page size, a gone record says so | `internal/server/record_block_test.go` |
| Tabs are canvases | the tab bar appears with a second canvas and marks the current one, a tab shows only its blocks and opens on a chat, what is said on a tab is built there, an expanded block leads back to its tab | `internal/server/tabs_test.go` |
| Model makes and fills tabs | create_canvas, blocks land on the tab the person is on or the one named, the prompt lists the tabs and the current one's blocks, clear_canvas clears one tab, remove_canvas takes its blocks | `internal/chat/canvases_test.go` |
| A block set up wrong says so | a list, chart, calendar or tracker asked for a type, field, date field, condition or tag the workspace does not have says it cannot be shown, one way everywhere (the problem component), with what is wrong and what there is instead under What is wrong, never an empty month or "Nothing tracked yet" | `internal/server/problem_test.go` |
| A block is checked when written | add_component, update_component, propose_change, add_arrangement, the same over MCP, and POST or PATCH /api/block resolve a block as its page will before writing it: one that could only say it is set up wrong is refused (a tool error, 422 cannot_show over the API) with the page's own reason and fix, and nothing is written; one that can be shown says what it shows ("3 tasks, not done, by due"); a look lists each block on a page that cannot be shown under problems; a block stored before still renders its problem | `internal/server/check_test.go`, `internal/mcp/check_test.go` |
| An action comes back where it was taken | every form in a canvas block says its block with no script, a closer place (a card, a row, a board's Move button) sent after it wins, only an id is taken, the page returns there with the outcome, and a control returned to hears it as its description; a move to where a record already is saves nothing and says so; a saved edit of one field says what it became and was, a ref by its title, long text only that it changed | `internal/server/back_test.go`, `internal/server/board_test.go`, `tools/a11y-runner/move.mjs` |
| A page for a job is a press away | Templates (/templates; Use this template is the owner's, POST /templates/use) offers every arrangement (week, reading, writing, trip, clients, a job search, a house move, recipes, studies, a budget, health) with what it is for and the kinds it would add; one press (chat.UseTemplate) makes the kinds it needs, a tab named for it, and its blocks there, each a change in the log; every template applies in a fresh workspace with no block set up wrong; linked from the new workspace's welcome and Help |`internal/server/templates_page_test.go` |
| A template is said before and after, and undone in one | Templates are filed by title as an index files them (The move under M), each saying what its tab shows by its blocks' headings and the kinds it adds, in words to the person; one already used links to its tab and says another use makes another, named Job search 2; the outcome says what was made ("Job search is a tab of its own now. It keeps applications.") with Undo, and the tab and its blocks are one Activity entry, so that one Undo takes them all back while the kind stays; an agent presses the same button through look and reads the same words (design/arrangements/README.md) |`internal/server/templates_page_test.go` |
| Layout now says the phone's first screen | measured on the person's phone, Layout now says which blocks the first screen (about 700px) shows and how long the tab runs there in pixels and screens, and on a tab longer than three screens to put what the person comes for first and take away what they do not | `internal/chat/layout_phone_test.go` |
| Adding beside a similar block says so | a collection, calendar, chart or single record added on a tab that already has one of the same component over the same records, or a second tracker, is added and says which block was there, what it shows, and to undo and update that one if the person meant it changed; one over other records says nothing | `internal/chat/tools_similar_test.go` |
| Clutter is said where the model looks | a block that can no longer be shown (a component gone, props that no longer pass, a record source the workspace lost) and a block the same as an earlier one are said once each, on one line, in Layout now (at the start of a turn and after every write) with propose taking it away; how to take a block away (propose_change, then remove_component or remove in arrange_canvas) is said once at the end; a stored block is never said as a refused write ("nothing was saved"), and the block lines carry no flags of their own | `internal/chat/layout_clutter_test.go` |
| The tab list says what each tab holds | the tabs the model is given say what is on each other tab by the names its blocks go by (Garden: Beds to dig, Seeds, and 3 more), and that a tab with nothing on it is empty, so a model adds to the tab that has the thing and sees a tab left over | `internal/chat/canvases_held_test.go` |
| A tab can be tidied in one press | a tab with blocks that cannot be shown or repeat another says how many under its tabs to whoever may change it, and names each and why (“Weather” is here twice; a button cannot be shown), with Tidy this page: one change that takes those it named away and only those still broken or repeated, never one that broke after, which one Undo puts back; one block is said as one; a block that shows nothing yet is not offered; a tidy tab, and anyone who may only look, sees nothing (design/foundations/layout.md) | `internal/server/canvas_tidy_test.go` |
| How the tab reads is given at the start | the prompt carries Layout now for the tab the person is on, the same text a write returns and /api/look gives (rows by name, panes, the phone, what is to look at), under the block lines; when there is something to look at it says to raise it when it bears on what is asked and fix it when changing the tab anyway, not to tidy unasked; a tab with nothing wrong gives its rows and nothing to look at | `internal/chat/layout_start_test.go`, `layout_test.go` |
| A heading with nothing under it is said | Layout now says a section heading with nothing under it (the last block, or straight before another heading), as when what it named was taken away, with put what it names under it or remove it; a heading with its section under it is not said | `internal/chat/layout_heading_alone_test.go` |
| A block that copies records is said | Layout now says a block that lists three or more records of one type as words with their links (a list of note titles, each with /t/note/<id>) copies them, and they stay as they are when the records change, are done or go: a collection of that type shows them and stays current, with update_component to make it one unless the person asked for a list that does not change; a link or two in a sentence is not said | `internal/chat/layout_copies_test.go` |
| The canvas says what each block shows | the canvas the model is given says beside each block what it shows now, as the person sees it ("shows: 2 tasks"; "shows: nothing yet"), from the same resolving that finds a block that cannot be shown, so the model judges a block by what it shows and not only its props | `internal/chat/block_shows_test.go` |
| The canvas says when and by whom each block was added | the canvas the model is given says beside each block how long it has been there and who put it there ("added 9 days ago by an agent", "added today by the assistant"), so a one-off left days ago reads as left over beside what the person asked for | `internal/chat/block_age_test.go` |
| A block that copies records by title is said | a line of a block's words that is a record's title (after a list mark, a checkbox, a link's words), three or more of one type, counts as a copy as a link does: Layout now says copies 3 tasks as words; lines that are no record's title are only words | `internal/chat/layout_copies_titles_test.go` |
| A tab can be renamed | rename_canvas gives a tab another name, which the tabs say from then on, as one change one Undo takes back; Home keeps its name and two tabs are never called the same | `internal/chat/canvas_rename_test.go` |
| Laying out can take blocks away | arrange_canvas takes remove, ids of blocks to take off the tab in the same change as the layout: one entry and one Undo that puts them back; a block both listed and removed, or not on the tab, is refused with nothing changed; a block left out is said missing with remove offered | `internal/chat/arrange_remove_test.go` |
| What may be left over is said | Layout now says a block an agent or the assistant added a week or more ago that has shown nothing since, with how long and why (there are no notes), to propose taking away; a block added today, or one that shows something, is not said | `internal/chat/layout_leftover_test.go` |
| A block another tab already shows is said | a block added over the same records as one on another tab says which tab has it by name (Work has id (Work tasks)), to keep when the person wants them here too or take back and link to that tab; a block over other records says nothing | `internal/chat/tools_similar_tabs_test.go` |
